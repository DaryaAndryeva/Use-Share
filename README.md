# Use & Share

Маркетплейс аренды вещей у соседей (Москва): оплата и залог через сервис, контакты открываются после брони.
Учебный проект, проектный семинар ПР, 4 курс — Перелайко Андрей, Андреева Дарья.

## Что здесь

| Путь | Что это |
|---|---|
| `site/` | Фронтенд (демо без сервера): React 19 + TypeScript, React Router, Vite. Данные синтетические, хранятся в `localStorage`. |
| `schema.sql` | Схема базы данных MVP, PostgreSQL 16 (7 таблиц). |
| `erd.html` | ER-диаграмма и описание функциональности через user stories — открывается в браузере. |
| `docs/` | OnePager, PRD, SRS, User Stories, RTM. |

## Запуск сайта

```bash
cd site
npm install
npm run dev      # разработка
npm run build    # сборка в site/dist
```

Сборка — статические файлы, их можно отдать любым веб-сервером. Маршруты через `#/…`, отдельная настройка сервера не нужна.

## Дизайн

Направление «Указатели»: городская навигация к вещам соседей — цвета линий метро для категорий, жёлтая метка «вы здесь», линия пути с минутами пешком. Подробности — `site/DESIGN.md`, продуктовый контекст — `site/PRODUCT.md`.
